# 📄 PaperExpress

概述：PaperExpress 是一个智能化论文速递工具，支持按 arXiv 学科分类和自由关键词检索最新论文。系统通过 LLM 自动生成中文摘要、一句话亮点和当前结果的趋势速览，并支持对单篇论文进行结构化精读分析。所有速递和精读结果会自动缓存，便于后续从历史记录中快速加载和导出 Markdown 报告。

## 功能

- **论文获取**：从 arXiv 获取指定主题的最新论文（支持 39 个计算机学科 arXiv 分类 + 自由关键词搜索）
- **自动翻译**：LLM 翻译摘要 + 提炼一句话亮点，支持 OpenAI 兼容接口
- **趋势速览**：基于当前结果生成 Topic、方法词、分类分布和发布日期统计
- **论文精读**：基于完整摘要进行深度分析，输出论文动机、方法详解、实验分析、局限性等结构化报告
- **历史记录**：自动缓存每次速递和精读结果，基于配置哈希快速命中，避免重复调用 LLM
- **导出报告**：翻译完成后导出 Markdown 文件

## 快速开始

### 1. 准备环境

项目使用 Conda 环境 `webDev`：

```bash
conda activate webDev
```

也可以基于 `environment.yml` 创建环境。

### 2. 启动服务

```bash
python server.py
```

服务默认启动在 `http://localhost:8080`，浏览器打开即可使用。

### 3. 配置 LLM

在项目根目录创建 `config.json`:

```json
{
  "endpoint": "https://api.deepseek.com",
  "key": "your-api-key",
  "model": "deepseek-v4-flash"
}
```

然后在页面点击「📂 加载配置」即可自动填充。也可以手动填写。

### 4. 使用流程

1. 点击「📋 加载完整学科分类」
2. 勾选你关注的分类，或输入关键词
3. 选择时间范围和最大论文数
4. 点击「🔗 测试连接」验证 API
5. 点击「🚀 开始生成论文速递」
6. 查看翻译结果、趋势速览和精读分析
7. 导出 Markdown 或从历史记录中重新加载
