# 📄 PaperExpress

概述：PaperExpress 是一个智能化论文速递工具，支持按 arXiv 学科分类和自由关键词检索最新论文。系统通过 LLM 自动生成中文摘要、一句话亮点和当前结果的趋势速览，并支持对单篇论文进行结构化精读分析。新增的研究 Agent 可以将复杂研究问题拆解为多步检索策略，自动完成查询理解、子查询生成、arXiv 检索、中文综述、质量评估和执行轨迹展示。所有速递、精读和 Agent 结果会自动缓存，便于后续从历史记录中快速加载和导出 Markdown 报告。

## 功能

- **论文获取**：从 arXiv 获取指定主题的最新论文（支持 39 个计算机学科 arXiv 分类 + 自由关键词搜索）
- **自动翻译**：LLM 翻译摘要 + 提炼一句话亮点，支持 OpenAI 兼容接口
- **趋势速览**：基于当前结果生成 Topic、方法词、分类分布和发布日期统计
- **论文精读**：基于完整摘要进行深度分析，输出论文动机、方法详解、实验分析、局限性等结构化报告
- **研究 Agent**：将复杂研究问题拆解为查询理解、多角度子查询、arXiv 检索、去重排序、智能综述和质量评估
- **执行轨迹**：展示 Agent 的规划、工具调用、观察结果和反思评估，便于理解每一步检索依据
- **历史记录**：自动缓存每次速递、精读和 Agent 结果，基于配置哈希快速命中，避免重复调用 LLM
- **导出报告**：翻译结果、精读结果和 Agent 研究报告均支持 Markdown 导出

## 快速开始

### 1. 准备环境

项目使用 Conda 环境 `webDev`：

```bash
conda activate webDev
```

也可以基于 `environment.yml` 创建环境。

### 2. 启动服务

```bash
python server.py
```

服务默认启动在 `http://localhost:8080`，浏览器打开即可使用。

### 3. 配置 LLM

在项目根目录创建 `config.json`:

```json
{
  "endpoint": "https://api.deepseek.com",
  "key": "your-api-key",
  "model": "deepseek-v4-flash"
}
```

然后在页面点击「📂 加载配置」即可自动填充。也可以手动填写。

### 4. 基本使用流程

1. 点击「📋 加载完整学科分类」
2. 勾选你关注的分类，或输入关键词
3. 选择时间范围和最大论文数
4. 点击「🔗 测试连接」验证 API
5. 点击「🚀 开始生成论文速递」
6. 查看翻译结果、趋势速览和精读分析
7. 导出 Markdown 或从历史记录中重新加载

### 5. 使用研究 Agent

1. 在页面顶部点击「研究 Agent」入口
2. 输入复杂研究问题，例如“大模型在缺陷修复领域的最新进展”
3. 选择时间范围、最大论文数和每个子查询拉取数量
4. 点击「运行研究 Agent」
5. 查看查询理解、多步搜索策略、质量评估、执行轨迹和代表论文
6. 导出 Agent Markdown 报告，或从历史记录中重新加载

研究 Agent 的实现逻辑详见 `agent/README.md`。
